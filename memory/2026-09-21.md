## Lessons

1. **Telegram replies carry the context.** When a bare answer like "A" arrives, check `reply_to_id` before asking what it means — message #482 was the whole question. I asked a round-trip I didn't need to.
2. **Lectern has a CLI — use it.** `cd /Users/6pffam/lectern && pnpm decide list --open` / `pnpm decide answer <id> <key> [--applied]`. The `/build` API route (`app/api/decisions/[id]/route.ts`) needs a PIN session cookie; the CLI doesn't.
3. **`decide list` doesn't print IDs.** Get them with a temp `.mts` script using `lib/prisma` run through `pnpm exec tsx`. Inline `tsx -e` fails on top-level await (cjs output).
4. **External `sqlite3` is blocked** against these DB paths by an OpenClaw guard — go through Prisma/the project's own tooling instead.
